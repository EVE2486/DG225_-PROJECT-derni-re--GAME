# [Melanie] — Game Concept [682110109]

## Elevator Pitch

[เป็นเกมแนว survival horror เป็นยุคล่าอาณานิคมหรือที่เรียกกันว่ายุคสมัยใหม่ ซึ่งผู้เล่นรับบทเป็นทหารเรือที่ออกตามหาความจริงเกี่ยวกับพ่อและแม่แต่แล้วเขาก็ได้ประสบอุบัติเหตุเรือล่มจากพายุปริศนาที่มีมอนเตอร์อยู่ข้างในนั้นดึงตัวไป พอลืมตาขึ้นมาก็พบว่าหลงมาอยู่ในต่างมิติ ซึ่งผู้เล่นต้องไขปริศนาระหว่างทาง พร้อมเผชิญหน้ากับสิ่งมีชีวิตที่คาดเดาไม่ได้ จงใช้ไหวพริบเพื่อหาทางรอดออกไปให้ได้]
